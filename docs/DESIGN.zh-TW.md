# SwitchPad 設計規範

iPad 殼（選擇遊戲、開始前設定、遊戲中選單、主機模式 iPad 畫面、虛擬搖桿調整版面）、手機手把網頁，和電腦端 Switch Pad 都照這份。改畫面前先看這裡，要加新的顏色或圓角先改這份。

## 原則

- **沉浸、精簡**：畫面上只寫玩家當下要做的事。捷徑自動化、著色器、env 檔、記憶體數字這類說明放 README，不放 App 裡。
- **Apple 簡約風**：深色石墨底、系統藍、連續曲率的圓角方形。不用膠囊和橢圓（實體手把的 ABXY、搖桿、狀態小圓點除外）。
- **資訊用小框標籤**：版本、上次遊玩、已暫停、網址這類短資訊放進小框（chip），不寫成句子。
- **格子不要太寬**：一格放得下圖示和名字就好。
- **每個動作都有回饋**：選取會滑動、卡片會彈出、按下會微縮。

## 顏色

| 用途 | 值 |
|---|---|
| 背景 | `#000000` |
| 卡片 / 次層 | `#1C1C1E` / `#2C2C2E` |
| 分隔線 | `#3A3A3C` |
| 主文字 / 次要文字 | `#F5F5F7` / `#8E8E93` |
| 強調色（選取、主要按鈕） | `#0A84FF`（Apple 深色模式系統藍） |
| 成功 / 警告 / 錯誤 | `#30D158` / `#FF9F0A` / `#FF453A` |
| 列底板 | 白 6–7% |
| 小框標籤底 | 白 12% |
| 細邊 | 白 10–12%，1 px |

**玩家色**（P1–P8，所有畫面一樣）：`#0A84FF` `#FF453A` `#30D158` `#FFD60A` `#BF5AF2` `#FF9F0A` `#40C8E0` `#FF375F`。玩家一律寫成「P1」，標籤是玩家色的圓角方形，字用黑色。

## 形狀

| 元件 | 圓角 |
|---|---|
| 大卡片（選單、玩家卡、提示卡） | 26（電腦端 16） |
| 列、主要按鈕 | 16（電腦端 9–12） |
| 圖示格、玩家標籤 | 10 |
| 小框標籤 | 7 |
| 遊戲圖示 | 邊長 × 0.2237（iOS 主畫面圖示圓角） |

iOS 一律用 `.continuous`（`kCACornerCurveContinuous`）。

## 材質

- 卡片是毛玻璃：`UIBlurEffectStyleSystemThickMaterialDark`（SwiftUI `.thickMaterial`）＋ `#14171C` 55% 疊色、白 12% 細邊、黑 45% 陰影（半徑 30、往下 14）。
- 卡片後面的遮罩：黑 55%。
- 選擇遊戲和開始前設定的背景：遊戲圖示模糊 60、放大 1.4、透明度 0.45–0.55，上面疊一層由淡到深的黑色漸層。
- 手機網頁的上方列和提示卡：`rgba(28,28,30,.72)` ＋ `backdrop-filter: blur(20–30px)`。

## 文字

| 用途 | 大小 |
|---|---|
| 大標題 | 34 bold（`.largeTitle`） |
| 卡片標題 | 22 bold |
| 列 | 17 semibold |
| 說明 | 13 |
| 小框標籤 | 12 semibold |
| 按鍵提示 | 「A 確定 · B 返回」，按鍵名放在小框裡 |

## 動畫

| 動作 | 數值 |
|---|---|
| 卡片出現 | 從 0.9 倍、往下 24 彈出：spring 0.45 秒、阻尼 0.74；遮罩 0.22 秒淡入 |
| 卡片關閉 | 0.2 秒縮到 0.94 倍並淡出 |
| 換頁 | 往深一層從右邊滑入 36，返回從左邊 |
| 選取移動 | spring 0.32–0.35 秒、阻尼 0.78–0.82；選中的圖示跳一下（1.12 倍） |
| 按下 | 縮到 0.94–0.96 倍、0.08–0.12 秒 |
| 開始遊戲 | 選中的遊戲放大 1.1 倍，其他淡出 |
