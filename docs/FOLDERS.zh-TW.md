# 資料夾說明（iPad 與電腦）

SwitchPad（iPad App）和 PadSwitch（電腦程式）用**同一套名稱**：同一款遊戲在兩邊都叫同一個資料夾名稱，存檔在兩邊都是「一個存檔一個資料夾」。
要自己加、刪、備份存檔或騰出空間，照下面找就對了。

遊戲名稱的寫法：遊戲本身的英文名稱，去掉 ™ ® ©，冒號和 Windows 不允許的字元換成空白（例如 *Unrailed 2: Back on Track* → `Unrailed 2 Back on Track`）。

## iPad（「檔案」App → 我的 iPad → SwitchPad）

| 資料夾 | 裡面是什麼 | 可以自己動嗎 |
|---|---|---|
| `存檔/<遊戲名稱>/<存檔名>/` | 一個資料夾就是一個存檔，資料夾名稱就是存檔名稱（開始遊戲前的「存檔」裡看到的名字） | 可以：複製出來備份、把別處的存檔資料夾放進來就多一個存檔、刪掉資料夾就刪掉那個存檔（正在用的那個除外） |
| `遊戲資料/<遊戲名稱>/` | 電腦傳過來的遊戲檔案（romfs、著色器 msl），最佔空間 | 可以刪來騰空間；下次電腦【同步】會再傳 |
| `著色器紀錄/<遊戲名稱>/` | 這台 iPad 玩的時候記下的著色器，電腦下次轉這款遊戲時會拿去用 | 不用動；電腦【同步】會收走 |
| `記錄/` | `log.txt`（最近一次）、`log.prev.txt`、每款遊戲最近兩次 `<遊戲名稱>.txt` 和閃退時的 `<遊戲名稱>.crash.txt` | 回報問題時用 |
| `系統/` | 暫存、管線快取、電腦的傳輸紀錄、`env.txt`、`folders.json` | 不用動 |

- 從其他模擬器、JKSV、Checkpoint 匯出的存檔就是「一包遊戲自己寫的檔案」，直接整個資料夾放進 `存檔/<遊戲名稱>/` 就好，資料夾名稱取你想要的存檔名。
- 存檔資料夾旁邊遊戲進行中會短暫出現 `<存檔名>.work`，是遊戲正在寫的暫存，遊戲結束就會消失，不要動它。
- 有「裝置存檔」的遊戲（例如 Mario Kart 8 Deluxe）另外有一份藏在 `存檔/<遊戲名稱>/.裝置存檔/<存檔名>/`。
- 目前使用哪個存檔記在隱藏的 `存檔/<遊戲名稱>/.存檔.json`；在開始遊戲前的「存檔」切換就好，不用改這個檔。
- 每個遊戲資料夾裡有一個隱藏的 `.titleid`，所以就算手動把資料夾改名，下次開 App 也會找回來並改回原名。
- 舊版的 `games/0100…`、`save/0100…`、`logs/`、`vk_capture/` 等，新版 App 第一次開啟時會自動搬到上面的位置（只是改名，不會重傳，也不會刪任何存檔）。

## 電腦（`Switch PAD` 資料夾）

| 資料夾 | 裡面是什麼 |
|---|---|
| `遊戲/<遊戲名稱>/` | 你的遊戲檔（.nsp / .nsz / .xci，本體、更新、DLC）直接放這層。新遊戲：開一個 `遊戲/<遊戲名稱>/` 資料夾把檔案丟進去 |
| `遊戲/<遊戲名稱>/存檔/<存檔名>/` | 跟 iPad 的 `存檔/<遊戲名稱>/<存檔名>/` 一模一樣，【同步】時兩邊互相補齊、不互相覆蓋（兩邊都改過就兩份都留） |
| `遊戲/<遊戲名稱>/存檔備份/` | 這款遊戲存檔被取代或刪除前留的備份，資料夾名稱是「時間 原因」 |
| `遊戲/<遊戲名稱>/著色器紀錄/` | 從 iPad 收回來的著色器紀錄，下次轉檔會用 |
| `遊戲/<遊戲名稱>/` 裡的 `<編號>_pack`、`<編號>_shader_cache`、`*-multi-*.ipa`、`precheck.json` | 轉檔時 PadSwitch 自己做的；刪掉也沒關係，下次【轉檔】會重做（只是比較久） |
| `遊戲庫/` | 合成好、要裝到 iPad 的 `遊戲庫.ipa` |
| `備份/iPad存檔/<時間 原因>/` | 每次動 iPad 存檔前，iPad 上全部存檔的快照，結構跟 iPad 的 `存檔/` 一樣 |
| `記錄/` | 從 iPad 拿回來的記錄（`iPad記錄/`）和匯出的問題回報（`問題回報/`） |
| `程式/` | PadSwitch 本身；`程式/舊版/` 是更新前的備份 |

要從備份救回某一款的存檔：到 `備份/iPad存檔/<時間>/<遊戲名稱>/` 把想要的存檔資料夾複製到 `遊戲/<遊戲名稱>/存檔/`，再按【同步】，iPad 上就會多出那個存檔。
